# v2.1 — 2026-11-24

## what changed
- pnpm working directory fixed
- guard added for missing package.json or build script
- launch examples use RemoteSigned

## what it means
the clone landed in the right folder, but pnpm ran in the shell folder instead. with no `package.json` there, install said `Already up to date`, then build failed with `Command "build" not found`. every pnpm call now gets an explicit working directory. if the clone layout is wrong, the tool stops before pnpm and says why. no launch example asks for `Bypass`.

## action needed
if you saw `ERR_PNPM_RECURSIVE_EXEC_FIRST_FAIL`, re-run the installer with the public command.
