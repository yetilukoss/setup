# v1.0 — 2026-11-22

## what changed
- first wpf gui
- four plugin cards
- repair, update, re-inject, uninstall
- log export

## what it means
you get a window instead of raw commands. pick a folder, choose plugins, watch progress. repair rebuilds after a game update. update pulls newer source. re-inject patches discord again. uninstall removes the patch but keeps your source folder. log export saves the full run so errors can be shared.

## action needed
none. this is the base build.
