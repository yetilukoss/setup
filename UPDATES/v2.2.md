# v2.2 - 2026-11-25

## what changed

- one encoded, hash-gated public command now works in PowerShell, cmd and Win+R
  without shell-specific escaping.
- the GUI cleanup action removes the Vencord injection only. settings, quickCss,
  themes, IndexedDB, backups, scripts, the repo clone, `dist` and all five
  userplugins stay on disk.
- the plugin tab now shows `Keep plugins (Recommended)` as the default action.
- the terms popup blurs the header, tabs and footer, and the agreed state stays
  latched after scrolling.
- the GUI terms now mirror `TERMS.md` exactly.
- license rows were corrected from verified upstream sources. Quest and
  bigFileUpload declare GPL-3.0-or-later in source headers. Vencord declares
  GPL-3.0-or-later in `package.json`.
- credit rows now include `creations` and `keircn` for bigFileUpload and Luca
  Burgio for Iconoir.
- privacy text now names plugin release checks and bigFileUpload external hosts.
- community plugins are explicitly described as not official, verified,
  endorsed or supported by Vencord or Discord.
- stale `iex` and execution-policy bypass strings were removed from shipped
  scripts.

## what it means for you

- paste one line from the README. no backticks, no shell-specific form.
- cleanup no longer wipes the cloned folder or preserved plugin files.
- the terms you accept on startup are the terms in the repo.
- license and network disclosures match what upstream projects actually say.
- the terms modal reads as a modal, not a dimmed tab page.
