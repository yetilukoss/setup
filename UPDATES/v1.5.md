# v1.5 — 2026-11-22

## what changed
- false pnpm-missing message fixed
- prerequisite helper now really installs pnpm

## what it means
the checker used to claim pnpm was missing even when present. the winget helper now performs a real install and refreshes path. if you saw a false missing warning, it was wrong. fresh machines benefit most.

## action needed
only if installing on a new pc: use the prereq helper.
