# v2.0 — 2026-11-22

## what changed
- inject uses official CLI with trusted exit codes
- progress stays responsive during git calls
- update touches only selected plugins
- terms match the repo exactly
- self-contained one-line launcher

## what it means
inject failures no longer get swallowed. the window keeps painting while git works. update skips plugins you did not select. the terms popup and `TERMS.md` say the same thing. one public command downloads one launcher file; the gui and console are bundled inside it.

## action needed
switch to the new public command if you still use `irm ... | iex`.
